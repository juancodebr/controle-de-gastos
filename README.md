# 💰 Controle de Gastos Pessoais

Projeto simples desenvolvido em Python para registrar despesas pessoais, listar os gastos cadastrados e calcular o total gasto.

## 📌 Sobre o projeto

O Controle de Gastos Pessoais foi desenvolvido como um projeto de aprendizado, com o objetivo de praticar os conceitos básicos da linguagem Python e criar uma aplicação simples para organização de despesas.

## 🚀 Funcionalidades

- Adicionar gastos com descrição e valor.
- Listar todos os gastos cadastrados.
- Calcular o total das despesas.
- Menu interativo no terminal.

## 🛠️ Tecnologias utilizadas

- Python 3
- PyCharm
- Git
- GitHub

## ▶️ Como executar

1. Clone o repositório:

   ```bash
   git clone https://github.com/juancodebr/controle-de-gastos.git
   ```

2. Entre na pasta do projeto.

3. Execute o arquivo:

   ```bash
   python versao1.py
   ```
